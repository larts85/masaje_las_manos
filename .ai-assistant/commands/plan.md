# Implementation planning

Use when the user requests analysis or a plan for this repository.

Read `AGENTS.md`, relevant application files and the relevant sections of `memory-bank/`. Prefer current code and package configuration when older documentation disagrees.

Identify affected routes, UI, authentication and database operations and legacy import. Compare plausible approaches and explain the recommended change, dependencies, risks and validation. Ask only questions whose answers materially affect the plan and cannot be inferred from the request or repo.

Deliver a concrete plan scoped to the user's objective. A request for analysis alone does not authorize implementation; when implementation is already requested, continue without adding a redundant approval step.
