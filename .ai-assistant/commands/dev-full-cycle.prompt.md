# Full development cycle

Use when the user requests implementation, validation and delivery.

Read the root `AGENTS.md` for the current repository context.

Inspect repository context, implement the requested change, run relevant available checks and verify the affected user flow. Use `.ai-assistant/commands/feature.prompt.md` or `fix.prompt.md` for implementation guidance. Inspect the final diff and report results. Create commits, PRs or deployments only within the authorized delivery scope; preserve unrelated local changes.
