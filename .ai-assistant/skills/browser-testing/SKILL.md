# Browser testing

Test, debug or visually inspect this repository in a browser.

Read the root `AGENTS.md` for the current repository context.

Use the available browser tools. Confirm the requested target URL; local development uses `http://localhost:2021` via the existing `yarn dev` script. Verify the affected shopping list, product, category, purchase history or sharing flow. Inspect visible state, console errors and network failures as needed. Google sign-in requires an authorized session; allow the user to complete interactive authentication when needed. Use authorized test data for persistent mutations. Capture relevant evidence and report what passed, failed or could not be verified.
